# Gerenciador de Tarefas MVC

Projeto desenvolvido com HTML, CSS e JavaScript utilizando a arquitetura MVC.

## Funcionalidades

- Adicionar tarefas
- Remover tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas
- Tema claro e escuro
- Armazenamento local com LocalStorage

## Tecnologias

- HTML5
- CSS3
- JavaScript ES6+
- MVC
- LocalStorage
